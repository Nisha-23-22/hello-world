# Laundry Wallah / Laundry Mart — HTML Assignment

## Project files
- `index.html` — complete webpage.
- `Readme.md` — project notes and instructions.
- `images/laundry-illustration.svg` — local laundry illustration used by the webpage.

## How to test locally
1. Extract the project ZIP into a folder.
2. Open the folder.
3. Double-click `index.html` to open it in your web browser.
4. Check the welcome heading, about section, image, services, price list, booking form, and footer.

The laundry illustration is stored locally, so the image does not require internet access.

## Included sections
- Welcome heading
- About Us introduction
- Laundry image
- Services list
- Price List table
- Book Now form with required name, email, and phone fields
- Footer contact email: info@laundrymart.com

## Note
This is a front-end HTML demo. The booking form validates required fields and shows a confirmation message, but it does not send booking details to a server.
